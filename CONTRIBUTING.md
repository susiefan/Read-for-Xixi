# Contributing

Keep changes focused on a concrete reading, authoring or evaluation problem. Explain resulting behavior, validation and material limits. Run the commands in README before submitting.

Do not commit book scans, full copyrighted text, narrated tracks, child media, unconsented family feedback, model weights or credentials. The selected library books stay local; changing a book selection does not grant redistribution rights. Reusable original companion artwork and general interaction rules are welcome.

Reading invitations are mandatory. Use one concise invitation and one brief response per page; preserve printed text and place translations in a separate field. Ground questions in the current picture, use natural language, embed a first-level cue, avoid spoilers, and allow gesture, imitation or a short answer. Rich, familiar ideas do not require a toddler to provide a complex verbal explanation.

For regressions, add a minimal synthetic structural test or an explicitly licensed case with provenance. Never invent human scores. Distinguish a blocking error from a stylistic suggestion, and preserve already accepted dimensions.

Redacted editorial ratings/comments may be contributed through the documented preview-and-explicit-consent workflow. Never include the underlying book scripts/scans/audio or child data. The included maintainer dataset is explicitly owner-authorized.
