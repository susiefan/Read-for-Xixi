# Confidential interaction profiles

Read-for-Xixi stores an interaction profile, not a cognitive age, IQ score, diagnosis, or speech assessment.

Keep language, reasoning, engagement, and support observations separate. Prefer parent-approved derived observations over raw child audio. Changes should be slow, reversible, visible to the caregiver, and isolated by language for multilingual children.

`interaction-profile.example.json` is synthetic and demonstrates the schema only.
