# Confidential voices

This folder represents the consent-gated voice pathway.

Do not commit reference recordings, child-name recordings, cloned speaker embeddings, generated narration, or consent documents. A production voice record should include the scope of consent, creation date, deletion state, storage region, and the family account authorized to use it.

The implemented prototype uses a locked natural Mandarin Mimi voice generated with CosyVoice 3. A parent-voice pathway is part of the architecture, but it should only render family reading content and must provide deletion controls.
